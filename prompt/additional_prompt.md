위 markdown 문서를 기준으로 Vite + React + Tailwind + Firebase 기반 Battery MES 프로젝트를 생성해줘.

조건:

- Dashboard 먼저 구현
- 좌측 Sidebar 포함
- Grid 기반 dense UI
- 공정 탭 구성
- Firestore 연결 포함
- 더미데이터 삽입 포함

---

# LEVEL 1

[현재 확인되는 개선해야 될 사항]

1. 더미데이터 활용:
 - 더미데이터를 이용해서 다양한 시나리오를 구현할 수 있어야 되어야함.
 - 시뮬레이션 시작 버튼을 실제로 기능이 있게 만들어서, 클릭되는 순간 더미데이터가 삽입되어서 실제로 공정이 흘러가는 모습을 실시간으로 모니터링하는 효과를 줘야함.
 - 종 모양 아이콘을 누르면 어디에 이슈가 발생했는지 바로 리다이렉트되는 기능이 구현되었으면 좋겠음.
 - 현재, mock data가 firestore에 저장해서 실시간으로 적절히 업데이트 되었으면 함.
 - 설비 관리 탭에 있는 기능들이 아직 완벽하지 않은 것 같음. 예를 들어, 대기 버튼을 누른 뒤, 다시 가동 버튼을 누르면 다시 정상적으로 돌아와야함.
 - 또, 최초의 상태로 돌리는 기능이 시스템 관리 탭에 추가되었으면 좋겠음. 이는 반복적으로 프로젝트를 디버깅 및 테스트 하는데 유용할 것 같음.

# LEVEL 2

[현재 확인되는 개선해야 될 사항]

1. 세부적인 기능 구현
 - 대시보드에 있는 '전체 생산 현황' 카드에서 날짜와 일간 이라는 텍스트가 있는데, 이를 이용해서 날짜는 클릭하면 날짜를 선택할 수 있는 달력이 나오도록 구현하고, 일간과 주간, 월간, 연간 탭을 클릭하면, 그에 맞게 일간/주간/월간/연간 데이터를 실시간으로 불러와서 대시보드에 띄워주면 좋을 것 같음.
 - 대시보드에 있는 '생산 추이'에 있는 '생산량', '가동률', '양품률'도 구체적인 기능이 존재했으면 좋겠음.
 - '품질 관리' 탭에 있는 '품질 이상 로그 (불량 목록 조회)'에서 해당 row를 클릭하면 모달창으로 불량에 대한 상세 정보를 띄워주면 좋을 것 같음. 또, MES에서 조치를 취할 수 있는 버튼이 모달창에 있어야함. 또, 'LOT 역추적 관리 (Traceability)'에 있는 '이력 추적' 기능을 LOT 번호만이 아닌 '발생 공정'으로도 검색할 수 있게끔 구현했으면 함. 또, 앞서 말한 MES에서 조치를 취할 수 있는 기능을 하게 되면 nav에 있는 종모양에서 알림 표시가 사라져야함.
 - nav에 있는 물음표 아이콘은 클릭하게 되면 현재 탭에 대한 간략하면서도 상세한 정보를 담고 있는 모달창이 띄워졌으면 함. 예를 들어, 대시보드 같은 경우, 전극 공정, 조립 공정, 화성 공정, 활성화 공정, 포장 공정의 6개 공정을 한 눈에 모니터링 할 수 있는 페이지이고, 각 공정은 실시간으로 데이터를 받아와서 표시하고 있습니다. 이처럼 각 탭의 성격에 맞게 물음표 아이콘을 클릭하면, 그에 대한 정보를 담은 모달창을 띄워주면 좋을 것 같음.
 - '생산 관리'에 있는 '신규 작업지시 생성' 버튼을 이용하면 신규 작업지시 생성 모달창이 띄워지는데, 이때 '목표 수량'만이 아닌 다른 자세한 통제 지시 사항을 입력할 수 있는 UI가 추가되었으면 함.

2. UI/UX 개선
 - 대시보드에 있는 전극 공정부터 모듈 공정까지의 카드들이 있는데, 해당 카드들을 클릭하면 해당 공정에 대한 자세한 정보를 가신 탭으로 이동했으면 좋겠음. 이는 현재 존재하지 않는 탭이므로 생성했으면 함. 예를 들어, 전극 공정 카드를 클릭하면 전극 공정에 대한 자세한 정보를 담은 탭으로 이동하며 믹싱, 코팅 & 건조, 프레싱(압연), 슬리팅 & 노칭에 대해 실시간 정보를 보여줬으면 함.

3. 출력물 구현
 - 리포트에 액셀로 현재 공정에 대한 정보를 다운받을 수 있게끔 구현했으면 함. 출력물의 형식은 바로 회사에 공유해도 좋을 법한 깔끔한 형식으로 구현했으면 함.

# LEVEL 3

[현재 확인되는 개선해야 될 사항]
1. 대시보드에 있는 '실시간 알림' 카드에 있는 목록들을 클릭하면 바로 해당 공정의 탭으로 이동했으면 좋겠음. 또, 해당 공정의 탭에서 불량이 발생한 행을 클릭하면 불량에 대한 상세 정보를 담은 모달창이 띄워졌으면 함. 또, 해당 카드에 내용이 비었을 경우, '불량 없음'이라고 표시되도록 구현했으면 함. 그리고 해당 카드 안에 내용이 너무 많아졌을 경우, 그 왼쪽에 있는 '전체 생산 현황'과 '생산 추이' 카드의 height가 같이 늘어나는게 보기 싫음. 카드들이 너무 높이가 커져서 보기 안좋음. 내용이 많아져서 길어질 경우 스크롤로 해결되도록 구현했으면 함.
2. 신규 작업지시 생성 모달창에 있는 목표 생산 수량 입력창에서 '유효한 값을 입력해 주세요. 가장 근접한 유효 값 2개는 600 및 1100입니다.' 라고 출력되는데, 이 부분을 조금 더 자유롭게 했으면 좋겠음.(숫자의 범위가 50부터 10000까지, 50의 배수만 입력 가능) 또, 이를 통해 만들어진 작업 지시도 시작을 눌렀을 때, 현재 더미데이터를 활용한 방식과 동일한 방식으로 실시간으로 공정이 진행되는 모습을 대시보드에 띄워주면 좋을 것 같음.
3. '품질 관리'에 있는 '품질 이상 로그 (불량 목록 조회)'에서 해당 불량 row를 클릭해서 나오는 모달창인 '품질 이상 상세 정보 & 즉각 조치'를 작성해서 '현장 조치 완료 (Clear Alert)'를 클릭하게 되면 더이상 nav에 있는 종모양의 알림의 숫자도 줄어들고, 대시보드에 있는 '실시간 알림' 카드에서도 해당 내용이 사라지도록 구현했으면 함.
4. '실시간 알림'에 있는 내용들중 정상화 완료와 같은 조치 완료, 작업지시 등록 완료 등의 내용들은 마우스 hover시 x를 표시해서 그 자리에서 없앨 수 있게 만들었으면 좋겠음. 대신 이상 감지나 경고 발생등은 클릭하게 되면 해당 공정으로 이동하여 바로 상세 정보를 볼 수 있도록 구현했으면 함.
5. '리포트' 탭에 '실시간 알림'에 있던 내용들이나, '품질 이상 로그'에 있던 내용들을 30일간 기록해두는 로그(Log) 카드가 따로 있었으면 좋겠음. 해당 로그는 x 같은 삭제 버튼이 따로 존재하지 않고 그냥 기록이 누적되다가 30일이 지나면 자동으로 사라지며, 로그 날짜, 나아가 시간별로도 조회할 수 있는 기능이 있으면 좋겠음.

# LEVEL 4

[현재 확인되는 개선해야 될 사항]

1. LEVEL 3 이후, '품질 관리' 탭에 row가 사라짐. 또, 대시보드의 '실시간 알림'에서 이상 감지 및 경고 발생의 내용을 클릭했을 때 기대했던 건 '품질 관리'탭으로 이동해서 '품질 이상 로그 (불량 목록 조회)'에 row에 추가되어있는 해당 row를 클릭한 것처럼 기존의 모달창이 나와서 조치를 취한 내용을 적고 '현장 조치 완료 (Clear Alert)' 버튼을 클릭하는 등의 조치를 취할 수 있게 되길 기대했음. 이 기능을 수정해줬으면 함.
2. '자재 관리' 탭에서 '자재 입고 등록' 카드에 있는 '입고 수량' input도 앞서 '신규 작업지시 생성' 모달창에서 '목표 생산 수량'에 했던 것과 동일하게 50부터 10000까지 50의 배수만 입력 가능하게끔 하고, 입고 버튼을 클릭하면 공정 관리에서 작업을 시작했을 때와 동일하게 '신규 자재 입고 등록'의 하위 작업들에 대해 실시간으로 작업 현황이 업데이트 되었으면 함.
3. 현재 Sidebar.jsx에 있는
```
          <div className="flex h-10 w-10 shrink-0 items-center justify-center rounded-sm bg-blue-600 font-bold text-white text-lg">
            B
          </div>
```
를 똑같이 svg로 만들어서 index.html의 head 태그에 넣어서 파비콘으로 나오게 끔 구현했으면 함.
4. 화성 공정과 모듈 공정은 현재 '생산 관리'탭에선 진행중인 것처럼 더미데이터를 잘 해놨지만, '추적 관리' 탭에선 해당 공정을 진행중인 Lot이 없고 '리포트'탭에선 생산수도 양품수도 불량률도 0인걸 확인할 수 있음. 실제로 가동중인 공장처럼 더미데이터를 좀 더 구체적으로 넣었으면 함.

# LEVEL 5

[현재 확인되는 개선해야 될 사항]

1. '품질 관리'탭에서 공정 단계 검색을 전체 공정(All)로 해두면 그 아래 나오는 LOT 리스트는 LOT-000035까지밖에 안나옴. 하지만 실제로 더미데이터에 있는 LOT은 000080까지 존재함. 즉, 공정 단계 검색이 모든 LOT을 다 보여주지 못하고 있음. 이를 수정했으면 함.
2. '품질 관리'탭에서의 '품질 이상 로그 (불량 목록 조회)'의 row에 ERROR 이상 등급은 nav의 종모양의 알림의 수에 영향을 주지 않는 것으로 보임. WARNING 등급은 영향을 주는 것으로 확인됨. 이를 확인하고 ERROR와 WARNING 모두 영향을 주도록 했으면 좋겠음.
3. '생산 관리'탭에서 신규 작업지시 생성 기능을 통해 만들어진 작업지시 row는 지시번호가 firebase의 .add 메서드에서 제공하는 기본 문서 ID값을 따라가는 것으로 보임. 이를 현재 더미데이터에 있는 지시번호처럼 WO-20260528-004 같은 형태로 규칙이 있었으면 좋겠음.
