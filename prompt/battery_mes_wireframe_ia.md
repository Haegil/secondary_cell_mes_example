# Battery MES 화면 설계서 (IA / Wireframe)

## 메뉴 구조
- Dashboard
- 실시간 현황
- 생산 관리
- 공정 관리
- 품질 관리
- 자재 관리
- 추적 관리
- 리포트
- 시스템 관리

## 1. Dashboard
### 주요 위젯
- 공정별 KPI 카드 (전극 / 조립 / 화성 / 모듈)
- 전체 생산 현황 Grid
- 시간대별 생산 추이 차트
- 실시간 알림 패널
- 설비 상태 현황
- 품질 현황
- 빠른 작업 실행 버튼

## 2. 생산 관리
- 작업 지시 목록
- 작업 생성 Modal
- 작업 상태 변경
- 진행률 표시

## 3. 공정 관리
공정 탭:
- 전극
- 조립
- 화성
- 모듈

공통 컬럼:
- LOT 번호
- 작업 상태
- 설비 ID
- 생산 수량
- 양품 수량
- 불량 수량
- 불량률
- 시작 시간
- 종료 시간

## UI 원칙
- Dense Grid Layout
- 14~16px 폰트
- 각진 카드 UI
- 키보드 + 마우스 입력 지원
